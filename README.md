# Evidencias — Elaboración de cocoa rojiza

Registro fotográfico de la **prueba de laboratorio** para la elaboración de cocoa rojiza.

Diseño **blanco limpio y ordenado**, pensado para enlazarse desde un informe técnico (botón / hipervínculo).

## Contenido

- 30 fotografías seleccionadas (de 80 originales)
- 7 secciones numeradas y coherentes:
  1. Resultado y comparación con el patrón
  2. Materia prima y textura
  3. Proceso en matraz
  4. Secado en bandejas
  5. Evolución de la coloración
  6. Montaje con tapa de aluminio
  7. Manipulación y trasvase
