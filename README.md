# Cocoa Rojiza — Evidencias de laboratorio

Registro fotográfico de la **prueba de laboratorio** para la elaboración de cocoa rojiza a partir de nibs de cacao.

La coloración obtenida se aproxima al patrón objetivo (rojo claro) del cliente Arron Foods / Machu Picchu Foods.

## Contenido

- **30 fotografías seleccionadas** (de un total original de 80)
- Organizadas en 7 etapas del proceso:
  1. Resultado y comparación con el patrón
  2. Materia prima y textura
  3. Proceso en matraz
  4. Secado en bandejas
  5. Evolución de la coloración
  6. Montaje con tapa de aluminio
  7. Manipulación y trasvase

## Mejoras respecto a la versión original

- Diseño editorial oscuro y cálido (sin Material Design / Google style)
- Tipografía serif para títulos + system UI para cuerpo
- Galería con hover sutil y lightbox con teclado (← → Esc)
- Solo las mejores imágenes (calidad y relevancia)
- Responsive y accesible
- Código limpio y ligero (HTML + CSS + JS vanilla)

## Cómo verlo
